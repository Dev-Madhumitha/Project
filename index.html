Interactive Snake Animation

A Creative Web Animation using HTML, CSS and JavaScript

About the Game

This is an interactive snake animation where the snake follows the movement of the user's cursor. It demonstrates mouse interaction and smooth animation.

How to Play

  • Move your mouse inside the animation area.
  • The snake follows your cursor.
  • Move the cursor in different directions.
  • Enjoy the interactive animation.

Features

  • Interactive cursor movement
  • Smooth snake animation
  • Dark gaming interface
  • Simple and user-friendly design

Technologies Used
